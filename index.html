🎵 音游

六键位下落式（S D F J K L） · 曲目互相独立 · 点击在新网页开始 ← 模块面板
曲库为空：先在 rhythm/music/ 下新建一个文件夹（文件夹名 = 曲名），
放一个 .mp3 进去（不用准备谱面），再跑一次 node rhythm/build.js
（在 rhythm/ 下则 node build.js；Windows 直接双击 rhythm/build.cmd —— 它会自动补好谱面再打包）。

本地新增曲目 / 皮肤（连谱面都自动生成）

新增曲目：在 rhythm/music/曲名/ 里放一个 .mp3 即可（不需要自己写谱面）
新增皮肤：在 rhythm/role/皮肤名/ 里放四张 png： Background.png / D.png / R.png / Trailing.png（缺图不报错，会降级；
想调整显示名或顺序可在该文件夹下加 skin.json，写 {"name":"显示名","order":10}）
然后跑 node rhythm/build.js，皮肤可在 多套，游戏页右侧「皮肤栏」会一一列出，点一下即换。
Windows 用户直接双击 rhythm/build.cmd：它会先为缺谱面的曲目自动生成谱面， 再重新打包曲库与皮肤 —— 打一次命令就够，已有的曲目和皮肤完全不会被改动。
